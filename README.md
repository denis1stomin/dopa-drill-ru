# Допа Дрилл (неофициальная русская версия)

Тренажёр по математике: с каждым решённым примером музыка и праздник на экране становятся всё сильнее. Работает прямо в браузере.

Это **неофициальная** русская версия игры [Dopa Drill (ドパドリル)](https://github.com/grmchn/dopa-drill), автор — gear_machine. Оригинал — на японском и по японской школьной программе.

Маскот Допакити (ドパキチ) переносит введённые цифры и радуется верным ответам. Чем дальше, тем больше эффектов и звука, а к концу — настоящий праздник. Ошибки не сбивают настроение, проигрыша нет.

## Что изменено по сравнению с оригиналом

- Весь интерфейс, подсказки, трофеи и коллекция — на русском, с правильными формами слов после чисел («1 пример», «3 примера», «5 примеров»).
- **58 навыков распределены по российской школьной программе** (1–4 класс — начальная школа, 5–6 — основная): таблица умножения на 2 и 3 во 2 классе, остальная — в 3-м; деление уголком — в 4-м; десятичные дроби, проценты и округление — в 5-м; НОД, НОК, сокращение и действия с обыкновенными дробями — в 6-м. Подробности — в [docs/curriculum.md](docs/curriculum.md).
- **Школьная запись**: десятичная запятая (2,5), деление двоеточием (12 : 4), остаток «17 : 5 = 3 (ост. 2)», смешанное число «2 1/3», «НОД(12; 18)», «25% от 200».
- **Деление в столбик — уголком**, как в российской школе: делимое слева, делитель за уголком справа, частное под ним, знак «−» перед каждым вычитаемым.
- Допа показывается с русскими единицами: «31 тыс.», «1,6 млн».
- Календарь начинается с понедельника.
- Шрифты пересобраны с кириллицей.

Идентификаторы навыков и формат сохранений не менялись, чтобы было проще переносить исправления из оригинала (`git fetch upstream`).

## Возможности

- 58 навыков счёта для 1–6 классов: сложение, вычитание, умножение и деление, столбик и уголок с промежуточными шагами, десятичные и обыкновенные дроби, проценты, пропорции, уравнения
- «Мой уровень»: начинается с проверки уровня и открывает новые навыки по мере освоения
- Режимы по классам, тренировка, работа над ошибками, дерево навыков
- Все примеры решены — 100 очков. Если 80% решено с первого раза, открывается экстра на время, где можно набрать больше 100
- Вся музыка и звуки синтезируются Web Audio API (звуковых файлов нет)
- Телефон в вертикальном положении и компьютер; на компьютере можно вводить цифры с клавиатуры и стирать Backspace
- В настройках можно уменьшить анимацию и выключить звук
- Все записи хранятся только на устройстве (localStorage) и никуда не отправляются

## Как запустить

Сборка не нужна — достаточно раздать папку `app/` как статический сайт:

```bash
python3 -m http.server 8000 -d app
```

Откройте в браузере `http://localhost:8000/`. Игра использует ES-модули, поэтому открыть файл напрямую (`file://`) не получится.

## Тесты

Нужен Node.js 20 или новее.

```bash
node --test tests/*.test.mjs
```
